# Easy-Calculator
This is a basic Java calculator program that performs various mathematical operations on two numbers

When you run the program it asks you to enter two numbers

Then it shows a list of available operations and asks you to choose one by entering a number

The available operations are

1 addition
2 subtraction
3 division
4 absolute value
5 power
6 square root
7 round
8 ceiling
9 floor
10 maximum
11 minimum

After selecting an operation the result is printed

Most operations are performed on both numbers and both results are shown

All logic is written in Main.java

This project is created for practice using Scanner and Math methods in Java
